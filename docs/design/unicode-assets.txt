YeuX Harness · Paper Signal terminal asset sheet
Version: 1.1 · 2026-08-31

The first column is the preferred UTF-8 appearance. The second column is the
stable ASCII appearance used by --ascii, TERM=dumb, non-UTF-8 locales, and
width detection failures. State words and effect text are mandatory; glyphs
are never the security boundary.

IMPLEMENTATION NOTES
  * Use grapheme-aware wrapping and wcwidth/wcswidth; never slice UTF-16 units.
  * Treat ambiguous-width glyphs as optional decoration and fall back to ASCII
    when the terminal reports an unexpected width.
  * Keep state words, effect names, targets, approval default, and replay mode
    in every output mode. Color and animation are only secondary signals.
  * Do not pass model/plugin/MCP control sequences through to a human terminal.
