# Third-party notices

YeuX Harness is a clean-room implementation informed by public agent harnesses.
No source code from those projects is vendored in this repository.

Rust and TypeScript dependency licenses must be audited before release; the
automated CI license gate is an M5 deliverable and is not present in this
development baseline. If source code or assets are incorporated later, their
copyright and license notices must be added here before release.
